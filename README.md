# SRCAS Hackathon 2.0 🚀

Welcome to the official website repository for **SRCAS Hackathon 2.0** - Tamil Nadu's premier 24-hour coding marathon!

## 🎯 About

SRCAS Hackathon 2.0 is an exciting innovation challenge that brings together brilliant minds to solve real-world problems in **Cybersecurity**, **Sustainability**, and **Smart City Solutions**. This 24-hour in-person hackathon is designed to foster innovation, collaboration, and technical excellence among college students.

## 🎯 Problem Statements

The hackathon features **8 exciting problem statements** across three domains:

1. **Cybersecurity Solutions** (5 problems)
2. **Sustainability & Environment** (2 problems)
3. **Smart City Solutions** (1 problem)

Visit the website to explore all problem statements in detail!
